## LNX standart rapor katmani

Logo ayrica cok sayida LNX_... gorunumu uretir: bunlar standart rapor/tarayici (browser) altyapisidir; firma/donem/rapor basina otomatik olusur ve dahili kullanilir. Tek tek belgelenmemistir; sorgularda dogrudan tablo/LV_ gorunumlerini tercih edin.
